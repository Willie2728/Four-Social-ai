# Four-Social AI

Source-of-truth handoff repository for the 4-Social / Implement AI product.

## Current status

The live Base44 application is currently the operational implementation. This repository is the GitHub source-of-truth and Codex/Remotion handoff target.

Important: do not assume a feature is live merely because UI exists. The Base44 forensic audit has identified mock data and controls without production handlers. See the docs directory.

## Product direction

4-Social is an AI-powered social, creator, marketing, commerce, analytics, and autonomous-workforce operating environment. Implement AI is the orchestration layer coordinating role-specific AI departments and agents.

Core requirements:
- Create once, adapt and publish everywhere
- Unified social inbox and engagement workflows
- Provider-neutral LLM gateway
- Photoreal conversational avatar runtime
- AI Boardroom, Presenter Mode, and Proctor Mode
- Proactive agent workforce with approval levels and full audit logs
- Content studio and reliable short-form generation
- Unified paid-media, content, sales, and ROI analytics
- Creator storefront / monetization layer
- Transparent integrations, credits, quotas, failures, and retries
